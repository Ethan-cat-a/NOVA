# NOVA Copilot for macOS 1.7.9

This release makes the drawer handle easier to spot and gives the assistant panel softer outer edges.

- Adds a cyan-blue tint, brighter grip marks and a colored outline to the frosted handle.
- Rounds the panel's outer right corners and adds a subtle edge and shadow, while keeping the pull tab attached.

The universal macOS build supports Apple silicon and Intel Macs running macOS 13 or later.
