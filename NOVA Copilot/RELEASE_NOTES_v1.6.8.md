# NOVA Copilot for macOS 1.6.8

- CS Agent can search public GitHub repositories and read public repository files, issues, and pull requests. It cannot access private repositories or write to GitHub.
- Google Search stays a free, explicit handoff to Chrome. This release does not call a hosted web-search service.
- CS Agent replies stream as soon as the gateway receives text instead of waiting for its tool steps to finish.
- Buffered display updates and periodic chat-history saves reduce lag during long replies and scrolling.
- Live response text uses the system label color to prevent the brief white-text flash in light appearance.
- Word document creation and fill-in remain reviewable before saving.

Build 28 · macOS 13 or later

Released as v1.6.8 with a universal DMG and Sparkle update ZIP.
