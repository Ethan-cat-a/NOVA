# NOVA Copilot for macOS 1.9.0

This update makes NOVA’s drawer and streaming replies feel steadier during everyday use.

- Remembers the drawer handle’s vertical position separately on each display. Your existing saved position is kept on the display NOVA first opens on.
- Updates the streaming auto-scroll at most 30 times per second to reduce repeated layout work during long replies.
- Keeps response text streaming immediately; only the automatic scrolling is coalesced.

Universal macOS build for Apple silicon and Intel Macs running macOS 13 or later.
