# NOVA Copilot for macOS 1.5.6

This update adds compact source details for replies to requests with attached files.

- Expand **Source details** under a completed reply to see the filenames and PDF pages provided with that request.
- NOVA is asked to cite only filenames and page labels present in the supplied text.
- Source details stay collapsed by default to keep the conversation panel tidy.

## Install

Open the DMG and drag **NOVA Copilot.app** to **Applications**. This build is ad-hoc signed and not notarized with an Apple Developer ID, so macOS may ask you to approve it the first time.

## In-app updates

The EdDSA-signed Sparkle ZIP and update feed are published. Open NOVA and choose **Check for Updates** to install this release.
