# NOVA Copilot for macOS 1.8.0

This update keeps NOVA’s drawer tab available while you work in other apps and gives you a deliberate way to hide it.

- Keeps the drawer above other application windows, whether open or tucked to the screen edge.
- Adds **Hide NOVA Drawer Handle** to the Window menu. The menu bar item brings NOVA back when you want it.
- Removes the pin control because the drawer now stays in front by default.

The universal macOS build supports Apple silicon and Intel Macs running macOS 13 or later.
