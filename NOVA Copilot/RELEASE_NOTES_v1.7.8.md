# NOVA Copilot for macOS 1.7.8

This release makes the side drawer easier to pull and softer in appearance.

- Replaces the avatar block with a slim frosted handle, a small direction arrow and three grip marks.
- Tracks the pointer in screen coordinates while dragging, so the drawer no longer jitters as it moves.
- Snaps to the nearest fully open or tucked position when released. At exactly halfway, it opens.
- Keeps the handle attached to the drawer and preserves click, menu-bar and ⌘⇧Space controls.

The universal macOS build supports Apple silicon and Intel Macs running macOS 13 or later.
