# NOVA Copilot 1.5.1 source notes

## What's new

- Removes self-service email/password account creation from both desktop clients.
- Keeps Google sign-in and email/password sign-in for existing accounts.
- The precreated owner account can use its existing Google identity when its verified email matches the owner account.
- Keeps account authorization and usage limits on the server.

No 1.5.1 installer is published yet. The current downloadable installers remain version 1.5.0.
