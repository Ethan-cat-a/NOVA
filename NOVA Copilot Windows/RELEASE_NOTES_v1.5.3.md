# NOVA Copilot for Windows 1.5.3

## Startup fix

- Fixes a Windows startup error, “expected integer but got ui,” by formatting the `Segoe UI` default font family correctly for Tk.
- Keeps the guest profile, optional account sign-in, chat modes, document tools and update checker from 1.5.2.

## Install

Download and open `NOVA-Copilot-Windows-1.5.3.exe`. It runs without a Python installation or ZIP extraction. This build is unsigned, so Windows SmartScreen may show a warning.
