# NOVA Copilot for Windows 1.0.0

**Release channel:** Windows  
**Target systems:** Windows 10 and Windows 11  
**Supported hardware:** Lenovo ThinkPad and other compatible Windows PCs

## Included

- Floating assistant panel and right-edge launcher.
- Ctrl + Shift + Space global shortcut.
- System tray menu.
- Nova V8 connection and streamed chat replies.
- Fast, Hard Thinker, and Coding modes.
- Local conversation history.
- Explicit clipboard insertion.
- Keep on top and Launch at Login settings.

## Installation

Install Python 3.10+, open the `NOVA Copilot Windows` folder on Windows, and run `build_windows.bat`. The script creates `dist\NOVA Copilot.exe`. The executable is generated on the user's Windows device and is not included as a prebuilt binary.
