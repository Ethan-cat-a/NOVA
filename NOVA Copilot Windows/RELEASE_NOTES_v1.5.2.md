# NOVA Copilot for Windows 1.5.2

- Chat works without signing in. NOVA creates a guest profile when you send the first message.
- Guest and regular profiles can send up to 25 chat requests per UTC day. Existing Google or email/password sign-in remains optional.
- Adds one-time owner-code redemption in the Account panel for the private unlimited-use owner profile.
- The guest profile is stored on this device. Clearing NOVA’s saved app data can create a new profile and allowance.

The server enforces the daily and per-minute limits. The guest allowance is per profile, not a verified per-person limit.
