# NOVA Copilot for Windows 1.5.0

Released November 6, 2026.

## What's new

- Create an account or sign in with email and password. Chat is available after the email address is verified.
- Keep the session encrypted with Windows DPAPI and refresh it when needed.
- Use the authenticated NOVA Copilot gateway for chat. The server enforces the daily and per-minute limits.
- Regular accounts receive 25 messages per UTC day. The verified owner account has unlimited daily use.
- Add account controls to the app menu and sign out when needed.

## Before you start

Download and open the standalone `.exe`; Python and ZIP extraction are not required. Sign up with an email address, open the confirmation email, then sign in. The app does not include the model API key. Windows SmartScreen may show a warning because this build is unsigned.
